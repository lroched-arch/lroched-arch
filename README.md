# Lídia Roche

**Desenvolupadora web orientada al backend · 8 anys coordinant equips i projectes**

Construeixo aplicacions web pensant en el que hi ha darrere: dades ben estructurades, APIs clares i codi que un altre equip pugui entendre i mantenir.
Arribo a la programació després de gairebé una dècada organitzant persones, horaris i serveis en l'àmbit educatiu, i això es nota en com treballo: planifico, documento i em comunico.
Actualment completo el cicle de **Desenvolupament d'Aplicacions Web (DAW)** a l'Institut Joaquim Mir, amb especial interès pel desenvolupament en entorn servidor.

---

## Què aporto

- **Mentalitat backend:** disseny d'APIs REST, models de dades i lògica de servidor amb Python.
- **Treball en equip real:** flux amb branques, *merges* i versions etiquetades a Git, treballant per *sprints*.
- **Coordinació i comunicació:** experiència gestionant equips, resolent conflictes i fent de pont entre persones amb necessitats diferents.
- **Organització:** planificació i programació d'activitats, una manera de treballar que trasllado a la gestió de projectes de software.
